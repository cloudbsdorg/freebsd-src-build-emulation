## Installation Instructions

1. Extract the distribution:
   ```bash
   tar -xf base.txz -C /
   ```

2. Install kernel module:
   ```bash
   kldload emu_core
   ```

3. Configure security settings (see emu.conf.5 man page)

4. Start emulation daemon:
   ```bash
   /usr/sbin/emu start
   ```

## Build Configuration Options

### BHYVE_SUPPORT
- Default: `yes` (includes bhyve/VMM integration)
- Alternative: `BHYVE_SUPPORT=no` for standalone mode

### EMU_SECURELEVEL
- 0: Insecure (development)
- 1: Standard (default)
- 2: High (production)
- 3: Maximum (critical infrastructure)
